## Original learning content and gaps

63 short original briefs/recall prompts orient the learner but do not cover every official bullet.18 original single-answer sample questions cover selected objective fragments, with two questions per domain. Many objectives have no authored question; the UI explicitly says so. These easy introductory checks are not a mock exam, predictive score, official question bank or exam dump. Only the latest submitted result per sample is retained; no full historical attempt audit.

Nine shared **domain-level tabletop/scenario worksheets**, reused beneath objectives in their domain, provide prerequisites, safe steps and a self-check rubric. There are not63 distinct labs. Completing a worksheet never marks other objectives mastered. Evidence and help level are self-reported. No hardware control, malware execution, host OS changes or automatic hands-on grader is included.

Researcher’s read-only review found no wrong answer indices or unsafe prescribed actions in the initial18MCQs. It required three fidelity corrections, applied here: gateway question maps to2.6; DNS question tests service/port53 under2.1; Linux question identifies read-only journalctl under1.9. ## Choosing other materials

Messer’s current free course plus the official checklist is a sound default. Buy missing capabilities rather than a duplicate course. If the learner already owns current Messer practice PDFs, use those privately. Consider structured simulated labs such as TotalSims when device access is missing; its advertised simulations are not proof of real-hardware competence and mobile compatibility must be checked. CompTIA CertMaster may fit existing school/employer access. This repository includes no paid product and makes no claim that one provider yields better pass outcomes. Prices and entitlements must be checked at purchase time.
